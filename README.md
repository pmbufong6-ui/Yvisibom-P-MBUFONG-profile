## Tailwind Utility-First Styling
Tailwind CSS was used alongside my custom CSS to improve the appearance and responsiveness of my webpage.
1. Navigation: Tailwind uitility classes were used to control the baclground colour, text colour, and spacing.
2. Contact section: Tailwind utility classes were used for spacing, width, background colour, rounded corners, and shadow.
3. Responsive utilities: I used responsive variants such as sm: and lg: to adjust spacing at different screen sizes.
4. Custom CSS: My external css/style.css file remains responsible for the styles that i chose to manage separately.
The combination of Tailwind utilities and custom CSS was intentional. Tailwind made common styling tasks easier, while custom CSS allowed me to retain control over the overall design and specific layout requirements.
